# Decisions

This file records decisions that should remain stable unless deliberately revisited.

## D001 — V0 target user

**Decision:** Professional interior designers.

## D002 — Core outcome

**Decision:** Five useful, purchase-ready recommendations, not an endless search feed.

## D003 — Platform

**Decision:** Responsive web app, desktop-first, for V0.

## D004 — Constraint philosophy

**Decision:** Separate hard constraints from soft preferences.

## D005 — Trust

**Decision:** Live commerce facts require evidence/observation state. Unknown is preferable to fabrication.

## D006 — Architecture

**Decision:** Keep AI, search, verification, storage, analytics, and data access behind small interfaces/adapters.

## D007 — V0 scope control

**Decision:** Voice, live camera, AR, native mobile, checkout, procurement, and full project management are excluded.

## D008 — Result-count behavior

**Decision:** Target five recommendations. Return fewer rather than knowingly violate hard constraints.
