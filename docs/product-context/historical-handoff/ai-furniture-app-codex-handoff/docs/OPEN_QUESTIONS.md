# Open Questions

These are intentionally unresolved. They should not block Phase 0/1.

## Product/search data

- Which provider gives the best coverage of design-oriented furniture?
- Do we need separate web-search and shopping-search providers?
- Which retailer APIs or feeds are worth integrating?
- What source terms permit image display or caching?

## Delivery

- What minimum user location is needed: city, ZIP/postcode, or full address?
- Can destination-aware delivery be verified reliably?
- How should freight / white-glove lead times be modeled?

## Product identity

- How reliably can SKU/brand/model be extracted?
- When are two listings the same underlying product?

## Image similarity

- Is multimodal LLM analysis enough for V0?
- Do we need embeddings for candidate/reference similarity later?

## Authentication

- Magic link, Google, or both?

## Early user test

- Which designers are in the first 5–10 testers?
- Which product categories best represent real pain?
- Which tasks should be run as controlled Google/Pinterest baselines?
