# Homely v3 — decision-flow drawing

Open `Homely-UI-Decision-Flows-v3.drawio` (or the identical `.drawio.xml` copy in Downloads) in diagrams.net/draw.io. No embedded screenshots: boxes, diamonds, text and connectors are native editable shapes. Pages 00–08 are integrated journeys; supplemental exact-state pages follow. Linked state boxes and blue destinations open next choices. Use page tabs or the “Journey map” link to return.

Start with [overview PNG](Homely-v3-journey-00.png) / [SVG](Homely-v3-journey-00.svg). SVG/PNG previews are static; hyperlinks are in the editable XML. The drawing is a finite proposed UI model, not an app or a guarantee of stock/visualization/source capability. The browser was not opened and an interactive import was not tested.
