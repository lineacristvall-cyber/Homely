# Operative Homely agent guidance

Read root `PROGRESS.md`, `DECISIONS.md`, `OPEN_ACTION_ITEMS.md`, and `CONTRACTS.md` at the start of each work session or resume. The current product decisions in `docs/product-context/CURRENT_CONTEXT.md` supersede historical V0 material; the accepted UX and architecture are in `docs/product-context/flows/` and `docs/product-context/architecture/`.

Keep exact stock truth, actual-product image lineage, independent numeric fit, hard spending cap, and pre-disclosure share access intact. Fictional/demo content must be labeled; never represent a search hit as verified stock. Never expose API keys to browser code, logs, screenshots or commits.

Workers edit only supervisor-assigned files. Report completed edits, tests, failures, blockers and next steps to supervisor. Supervisor owns shared logs and updates them at meaningful changes and before handoff; `OPEN_ACTION_ITEMS.md` contains only unresolved tasks, and resolved items move into `PROGRESS.md`.
